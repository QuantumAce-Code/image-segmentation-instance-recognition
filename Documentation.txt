## 2. Mask R-CNN Implementation

### Architecture Overview

Mask R-CNN extends Faster R-CNN by adding a branch for predicting segmentation masks in parallel with existing branches for classification and bounding box regression. Though introduced in 2017, it remains a reliable and widely-used approach for instance segmentation tasks.

### Step-by-Step Process

1. **Feature Extraction**:
   - Uses a backbone network (ResNet-50-FPN) to extract feature maps from input images
   - Feature Pyramid Network (FPN) provides multi-scale feature representations

2. **Region Proposal Network (RPN)**:
   - Generates region proposals (potential object locations)
   - Assigns anchors to ground-truth object boxes
   - Filters proposals using non-maximum suppression

3. **ROI Alignment**:
   - Extracts features from each region of interest
   - Preserves exact spatial locations for accurate mask prediction

4. **Detection Head**:
   - Performs classification (object category)
   - Refines bounding box coordinates

5. **Mask Prediction**:
   - Generates a pixel-wise mask for each ROI
   - Predicts masks for each class independently

6. **Post-processing**:
   - Applies threshold to obtain binary masks
   - Combines outputs to produce final instance segmentation

## 3. U-Net Implementation with Instance Recognition

### Architecture Overview

U-Net features an encoder-decoder architecture with skip connections. Our implementation extends the classic U-Net (originally from 2015) with additional heads for instance-aware segmentation, creating a reliable solution for combined semantic and instance segmentation.

### Step-by-Step Process

1. **Encoding Path (Contraction)**:
   - Series of convolutional blocks and max-pooling operations
   - Each step doubles the number of feature channels
   - Captures context and semantic information

2. **Decoding Path (Expansion)**:
   - Series of up-convolutions and concatenations with encoder features
   - Skip connections preserve fine spatial details
   - Gradually increases resolution back to input size

3. **Multi-Head Output**:
   - **Semantic Head**: Produces pixel-wise classification (foreground/background)
   - **Center Prediction Head**: Identifies instance centers
   - **Embedding Head**: Generates pixel embeddings to differentiate instances

4. **Instance Formation**:
   - Combines semantic mask and center predictions
   - Groups pixels into instances using embedding similarity
   - Assigns unique colors to each detected instance

5. **Post-Processing**:
   - Connected components analysis for instance separation
   - Distance-based pixel assignment to instance centers
   - Visualization with unique colors per instance
